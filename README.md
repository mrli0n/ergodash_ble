# Ergodash BLE

[![Build](https://github.com/mrli0n/ergodash_ble/actions/workflows/build.yml/badge.svg)](https://github.com/mrli0n/ergodash_ble/actions/workflows/build.yml)

ZMK firmware for the wireless Ergodash split keyboard (nRFMicro 1.3 / nRF52840), kept up to date with the latest [ZMK](https://zmk.dev).

## Hardware

- nRFMicro 1.3 (nRF52840, Bluetooth 5) on each half
- Hot-swappable switches
- Per-key RGB (SK6812, 35 LEDs per half)
- 110 mAh battery per half, charged at 100 mA
- Fully wireless split: no TRRS cable, the halves always talk over Bluetooth

## Getting the firmware

Every push builds the firmware with GitHub Actions.

1. Open the [Actions tab](https://github.com/mrli0n/ergodash_ble/actions) and pick the latest successful run.
2. Download the `firmware` artifact and unzip it. It contains:
   - `ergodash_ble_left-nrfmicro@1.3.0_nrf52840_zmk-zmk.uf2`: left half
   - `ergodash_ble_right-nrfmicro@1.3.0_nrf52840_zmk-zmk.uf2`: right half
   - `settings_reset-nrfmicro@1.3.0_nrf52840_zmk-zmk.uf2`: clears stored pairings

To change the keymap, fork this repo and edit [`ergodash_ble.keymap`](boards/shields/ergodash_ble/ergodash_ble.keymap). Your fork's Actions builds the firmware for you. The available key codes are listed in the [ZMK docs](https://zmk.dev/docs/keymaps).

## Flashing

1. Plug one half into your computer over USB.
2. Double-press its reset button. The green LED pulses and a USB drive appears.
3. Copy that half's `.uf2` file onto the drive. It ejects itself when flashing is done.
4. Repeat for the other half.

Flash both halves from the same build. The left half is the central: it connects to your computer, and the right half connects to it.

### Upgrading from the old firmware

This firmware is built on a much newer ZMK than the original. If the halves won't connect to each other after upgrading, clear the stored pairings:

1. Flash `settings_reset` to **both** halves.
2. Flash the left and right firmware again.
3. Press reset on both halves at the same time so they pair with each other.
4. Remove the keyboard from your computer's Bluetooth list and pair it again.

## Using the keyboard

- With the left half plugged in over USB, the keyboard works as a USB keyboard. Unplugged, it uses Bluetooth.
- USB mode is a quick way to check that the two halves are paired.
- Both halves go to sleep after 15 minutes idle. Press any key to wake them. The underglow turns off when the keyboard is idle.

## Building locally

Set up the [ZMK toolchain](https://zmk.dev/docs/development/local-toolchain/setup), then from an empty directory:

```sh
mkdir config && cp /path/to/ergodash_ble/config/west.yml config/
west init -l config
west update
west zephyr-export

west build -p -s zmk/app -d build/left -b nrfmicro@1.3.0/nrf52840/zmk -- \
  -DSHIELD=ergodash_ble_left -DZMK_EXTRA_MODULES=/path/to/ergodash_ble
west build -p -s zmk/app -d build/right -b nrfmicro@1.3.0/nrf52840/zmk -- \
  -DSHIELD=ergodash_ble_right -DZMK_EXTRA_MODULES=/path/to/ergodash_ble
```

The firmware ends up in `build/left/zephyr/zmk.uf2` and `build/right/zephyr/zmk.uf2`. ZMK doesn't handle spaces in these paths, so keep the repo and keymap in folders without spaces.

The shield is called `ergodash_ble` so it doesn't clash with ZMK's built-in `ergodash` shield, which is the wired version.

## Troubleshooting

**The USB drive doesn't appear in bootloader mode (the green LED is pulsing).**
Try another USB port or cable, reinstall the device driver, or restart the computer.

**The keyboard won't pair with the computer.**
Hold Raise and press **BT clear** (top row, 7th key on the left half) to clear the current Bluetooth profile, then pair again. If that doesn't help, follow the [pairing reset steps](#upgrading-from-the-old-firmware).

**The two halves won't connect to each other.**
Follow the [pairing reset steps](#upgrading-from-the-old-firmware).
